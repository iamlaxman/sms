01 / Mission

Why we built this

Existing SMS tools in Nepal are either locked behind corporate contracts, charge per message with minimum commitments, or are so generic that delivering a simple OTP turns into a week-long integration project. We wanted something a single developer could use in an afternoon.

SMS Adda is the result: a clean interface, a straightforward API, and a set of Nepali SMS gateways wired together so one call gets through even if a single provider is down. No dashboards to learn, no sales call, no minimum spend.

02 / Principles

What we stand for

Fast by default

Under five seconds from tap to delivered, or we rotate to the next gateway automatically.

Privacy first

We store nothing about your recipients. Phone numbers are passed through and never logged.

Always available

Six independent gateways mean one outage never takes the whole service down.

Simple API

One endpoint. One payload. No SDK, no auth dance, no complicated setup.

Nepal-only focus

Built specifically for +977 numbers. No wasted coverage, no dead routes.

No lock-in

Pay per message, use what you need, walk away whenever. No contracts.

03 / How it works

From send to delivered

You enter a number

Any valid +977 mobile — 98 or 97 prefix, ten digits. Add as many numbers as you like in bulk mode.

We validate and pick a gateway

The phone number is checked, then our worker picks a gateway from six available providers. In manual mode you choose; in auto mode we rotate until one accepts.

The SMS is dispatched

The chosen gateway sends the message. If it fails, we try the next one. You see every step in the live terminal trace.

Delivered to the phone

The recipient gets the message within seconds. Every send is confirmed in the response and logged in your session.
